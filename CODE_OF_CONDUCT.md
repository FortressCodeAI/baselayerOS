# Code of Conduct

BaseLayerOS is a governance substrate.  
All contributors must adhere to deterministic engineering principles.

## Core Values

- Determinism  
- Traceability  
- Governance  
- Invariant enforcement  
- Cross‑cloud consistency  

## Expected Behavior

Contributors must:

- write deterministic code  
- enforce governance boundaries  
- maintain invariant correctness  
- preserve replayability  
- avoid stochastic behavior  

## Unacceptable Behavior

- nondeterministic branching  
- ungoverned tool invocation  
- probabilistic execution  
- untraceable transitions  
- cross‑cloud inconsistency
