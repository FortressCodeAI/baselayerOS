# Kali — Deterministic AI Operating System

Kali is a deterministic AI operating system designed for governed execution,
audit‑anchored transitions, tenant‑aware workflows, and partner‑safe delivery.

Kali provides:

- Deterministic compiler
- Deterministic runtime engine
- Deterministic substrate client
- Deterministic marketing engine
- Deterministic sales engine
- Deterministic delivery engine
- Deterministic governance kernel
- Fully monitored console

All operations are deterministic, replayable, and governed by kernel invariants.

## Features

### 🔹 Deterministic Compiler

Compiles products into fully resolved manifests:

- modules  
- workflows  
- artifacts  
- delivery rules  
- invariants  
- constraints  

### 🔹 Deterministic Runtime

Executes:

- workflows  
- modules  
- substrate envelopes  

### 🔹 Deterministic Substrate Client

Handles:

- audit anchors  
- transition hashing  
- artifact generation  
- state versioning  

### 🔹 Deterministic Delivery Engine

Delivers manifests to:

- substrate  
- Supabase  
- tenant runtime  
- partners (Google CAGE, MayIAI)  

### 🔹 Deterministic Business Engines

- Marketing Engine  
- Sales Engine  

### 🔹 Deterministic Governance Kernel

- invariants  
- constraints  
- rulebook  

## Getting Started

### Build

`cargo build`

### Run

`cargo run`

This will:

1. Compile `marketing-pack`
2. Deliver it
3. Run a workflow
4. Run a module
5. Execute a substrate envelope

All with full monitoring output.
